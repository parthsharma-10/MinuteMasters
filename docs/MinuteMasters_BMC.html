🤝 8. Key Partners
  • LLM Infrastructure: Google AI Studio (Gemini 2.5 Flash), OpenAI, and Anthropic for scalable prompt inference.
  • Bennett University Ecosystem: Student societies (ACM, IEEE, GDSC), project batches, and faculty mentors for testing.
  • Open Source Community: Streamlit, LangChain, and Python ecosystem for rapid app development.
  • Collaboration Tools: Potential integration partners (Slack, Jira, Linear APIs).
⚡ 7. Key Activities
  • Prompt Architecture Tuning: Continuous calibration of extraction and adversarial verification prompts.
  • Pipeline Engineering: Optimizing low-latency Python orchestration and RFC 8259 JSON validation.
  • Edge-Case Benchmarking: Curating real-world transcripts with overlapping dialogue and code-switching.
  • User Feedback Integration: Conducting testing cycles with student club leaders and secretaries.
📦 6. Key Resources
  • Proprietary Prompt Workflow: Optimized two-stage P1/P2 prompt pipeline with verbatim quote grounding.
  • Evaluation Benchmark: 12 hand-labeled meeting transcripts with edge-case ground truths.
  • Technical Assets: Streamlit interactive web application and Python library.
  • Human Capital: 6-member engineering team specialized in prompt engineering and full-stack delivery.
💎 2. Value Propositions
  • Zero-Hallucination Guarantee: Decoupled adversarial verification ensures tasks are only assigned when explicitly consented.
  • Deterministic Fallback Transparency: Missing owners or deadlines are explicitly marked as "not stated" instead of being guessed.
  • Verbatim Quote Grounding: Every extracted decision and action is anchored to an exact transcript utterance.
  • Frictionless Export: 1-click generation of Jira-ready JSON and Slack-ready Markdown task tables.
  • Extreme Cost Efficiency: ~$0.0003 per meeting on Gemini 2.5 Flash—90% cheaper than enterprise recording bots.
❤️ 4. Customer Relationships
  • Transparency & Trust: Clear visual distinction between verified facts and unstated ambiguities; hover citations.
  • Self-Service Onboarding: Zero configuration; paste transcript and get verified tasks instantly.
  • Open Benchmarks: Community-accessible synthetic evaluation transcripts for open validation.
📢 3. Channels
  • Streamlit Web App: Direct browser-based paste-and-extract interface.
  • Chrome Extension (Roadmap): Live transcript capture from Google Meet / Zoom Web.
  • GitHub Marketplace / CLI: Developer automation for standup summarization.
  • Campus Word-of-Mouth: Student society deployments and hackathon pilot testing.
🎯 1. Customer Segments
  • Student Society Leads: Presidents, secretaries, and leads (ACM, IEEE, cultural clubs) managing busy meetings.
  • Student Project Teams: Capstone and hackathon teams running rapid agile standups.
  • SME Software Teams: 5–30 person engineering teams who find enterprise tools ($25/seat) opaque or unaffordable.
  • Academic Committees: Faculty note-takers requiring auditable meeting minutes.
💸 9. Cost Structure
  • LLM Inference Costs: ~$0.0003 per meeting transcript on Gemini 2.5 Flash (~$0.002 on GPT-4o).
  • Hosting & Compute: Free/Low-cost cloud hosting on Streamlit Community Cloud and Vercel ($0–$15/mo).
  • Domain & Infrastructure: Custom DNS and SSL maintenance ($12/year).
  • Development Effort: Student engineering team sweat equity and open-source tooling.
💰 5. Revenue Streams
  • Freemium Tier (Free): Up to 15 transcript analyses per month for students and individuals.
  • Campus Society Pass ($2.99 / semester / team): Unlimited runs, club templates, and bulk CSV export.
  • Startup Team Tier ($6 / seat / month): Direct Jira, Linear, and Slack sync with automated task creation.
  • Enterprise API Licensing: Pay-per-call API for institutional knowledge bases ($0.02 / call).
